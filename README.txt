===============================
ОПИСАНИЕ ПРОЕКТА И СТРУКТУРА
===============================
Консольная программа на языке C для поиска и замены бинарных последовательностей в файлах.

Особенности реализации:
* Память жестко ограничена размером буфера N байт (задается при компиляции).
* Чтение файла происходит строго один раз, без перемещений назад и сдвигов памяти.
* Поиск осуществляется "на лету" без предобработки шаблонов.
* Поддержка любых байтов (включая '\0') реализована через Hex-строки.

Структура проекта:
* app/ — исполняемое приложение (разбор CLI-аргументов и работа с файлами).
* lib/ — библиотека функций (Hex-декодер и алгоритм замены).
* cmake/ — скрипты автоматического подключения тестов.

==============================================
ИНСТРУКЦИЯ ПО ЗАПУСКУ И ТЕСТИРОВАНИЮ РЕШЕНИЯ
==============================================

1. Сборка проекта с нестандартным размером буфера N (например, 512 байт):
   > cd build
   > cmake -DN=512 ..
   > cmake --build . --config Debug

2. Запуск программы:
   Программа принимает файлы и hex-строки в качестве шаблонов поиска/замены.
   Пример (замена "AB" на "12" в файле input.bin):
   > ./app/Debug/my_program.exe input.bin output.bin 4142 3132

3. Запуск автоматических тестов:
   Все тесты (юнит-тесты и интеграционные тесты) можно запустить одной командой:
   > ctest -C Debug --verbose
