==============================================
ИНСТРУКЦИЯ ПО ЗАПУСКУ И ТЕСТИРОВАНИЮ РЕШЕНИЯ
==============================================

1. Сборка проекта с нестандартным размером буфера N (например, 512 байт):
   > cd build
   > cmake -DN=512 ..
   > cmake --build . --config Debug

2. Запуск программы:
   Программа принимает файлы и hex-строки в качестве шаблонов поиска/замены.
   Пример (замена "AB" на "12" в файле input.bin):
   > ./app/Debug/app.exe input.bin output.bin 4142 3132

3. Запуск автоматических тестов:
   Все тесты (юнит-тесты и интеграционные тесты) можно запустить одной командой:
   > ctest -C Debug --verbose
