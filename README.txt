========================================================================
ОПИСАНИЕ ПРОЕКТА И СТРУКТУРА
========================================================================
Консольная программа на языке C для поиска и замены бинарных последовательностей в файлах.

Особенности реализации:
* Память жестко ограничена размером буфера N байт (задается при компиляции).
* Чтение файла происходит строго один раз, без перемещений назад и сдвигов памяти.
* Поиск осуществляется "на лету" без предобработки шаблонов.
* Поддержка любых байтов (включая '\0') реализована через Hex-строки.

Структура проекта:
* app/ — исполняемое приложение (разбор CLI-аргументов и работа с файлами).
* lib/ — библиотека функций (Hex-декодер и алгоритм замены).
* cmake/ — скрипты автоматического подключения тестов.

========================================================================
ПОДРОБНАЯ ИНСТРУКЦИЯ ПО СБОРКЕ И ЗАПУСКУ В POWERSHELL (WINDOWS)
========================================================================

1. Очистка кэша и сборка проекта

# Удаляем старую папку сборки (если она была), чтобы избежать конфликтов кэша:
> Remove-Item -Recurse -Force build

# Создаем чистую папку для сборки и переходим в нее:
> mkdir build
> cd build

# Настраиваем CMake (задаем размер буфера например N = 4):
> cmake -DN=4 ..

# Запускаем компиляцию проекта:
> cmake --build . --config Debug


2. Ручной запуск программы и проверка замены

После успешной сборки исполняемый файл "my_program.exe" появится в подпапке 
"build/app/Debug/". 

Для ручного тестирования программы выполните следующие шаги:

1. Создайте текстовый файл "input.txt" строго внутри папки "build".
2. Впишите внутрь файла "input.txt" одну строку:
   HelloWorld
3. Сохраните и закройте файл.
4. Выполните команду замены слова "World" (576f726c64) на "Dima" (44696d61):
   > ./app/Debug/my_program.exe input.txt output.txt 0x576f726c64 0x44696d61 (0x перед аргументами)
   или
   > ./app/Debug/my_program.exe input.txt output.txt World Dima 



3. Запуск автоматических тестов

Вы можете запустить все 11 автоматических тестов (6 юнит-тестов для Hex-парсера 
и 5 интеграционных тестов для файлов) одной командой из папки "build":

> ctest -C Debug --verbose
